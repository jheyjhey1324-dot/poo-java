# 🏠 Simulador de Financiamento Imobiliário

Exercício da disciplina de Programação Orientada a Objetos simula um financiamento imobiliário em Java que compara quatro situações 
diferentes. 

## Sobre o projeto:

O programa solicita ao usuário os dados de 4 financiamentos (valor do imóvel, prazo em anos e taxa de juros anual), calcula o valor 
total de cada subsídio, exibe os detalhes de cada financiamento e por fim mostra um resumo geral com o total dos imóveis e o total da operação.
